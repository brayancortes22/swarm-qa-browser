# Checklist de UX

- [x] Cursores distinguibles por color; los cursores de rol muestran nombre y estado.
- [x] Movimiento con curvas y aceleración suave; duración proporcional a la distancia.
- [x] Cajas de selección con tiradores y medidas; marcador gris para imágenes; texto revelado carácter a carácter.
- [x] Barra de control con agentes activos, progreso de capas, contadores de tickets, Tour, Auditar, velocidad, sonido y minimizar.
- [x] Pines por severidad (`P1` rojo, `P2` ámbar, `P3` azul) que siguen a su elemento y se ocultan fuera de la vista.
- [x] Pines filtrados por ruta y clase de viewport.
- [x] El overlay no intercepta clics salvo en la barra y los pines.
- [x] `prefers-reduced-motion` desactiva transiciones y usa scroll instantáneo.
- [x] Botones con nombre accesible y foco visible; contadores con `role="status"`.
- [x] Consentimiento claro en español antes de activar el depurador.
- [ ] Tema claro para la barra en páginas oscuras (hoy la barra siempre es oscura y las reglas siempre claras).
